# 腾讯营销服务商准入指引助手

K1 竞价自助开放生态 · 准入办理与政策激励指引。纯静态页面，无需后端，支持电脑与手机访问。

## 在线访问

> 部署到 GitHub Pages 后，把下面的链接替换成实际地址即可分享给任何人。

https://<你的 GitHub 用户名>.github.io/<仓库名>/

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页面（需与 `styles.css` / `app.js` / `data.js` 同目录） |
| `styles.css` | 样式文件 |
| `app.js` | 交互逻辑 |
| `data.js` | 指引内容数据，更新文案只改这里即可 |
| `standalone.html` | 单文件完整版，样式与脚本已内嵌，适合单独通过微信 / 邮件转发 |
| `README.txt` | 使用说明（面向业务同学） |

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

也可直接双击 `standalone.html` 打开（离线可用）。

## 更新内容

指引文案全部集中在 `data.js`，改完提交并推送到 `main` 分支，GitHub Pages 会在 1～2 分钟内自动更新。

## 说明

- 页面为免登录模式，勾选进度仅保存在当前浏览器页面，刷新或关闭后清空，不会上传或同步到任何系统。
- 一站式平台体验账号在页面底部「② 帮助与支持」区域查看。
