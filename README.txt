【一、最快方式：在线访问（推荐，无需下载）】
直接用浏览器打开以下网址即可，手机、电脑都可以，谁拿到链接都能看：

【二、离线方式：只发一个文件给别人】
1. 在压缩包里找到 standalone.html（单文件版，样式和程序都已内嵌在里面）
2. 双击用浏览器打开；或直接把这个文件通过微信 / 邮件发给对方
3. 对方收到后双击即可查看，不需要解压、不需要联网、不需要装任何东西

【三、完整方式：解压后本地打开】
1. 把整个压缩包解压（Mac 双击即可，Windows 右键"全部解压缩"）
2. 进入解压后的文件夹，双击 index.html
3. 会用默认浏览器打开，功能与在线版完全一致

   注意：index.html 必须和 styles.css、app.js、data.js 放在同一个文件夹里，
   单独把 index.html 拿出来打开会没有样式。

【四、常见问题】
Q：勾选的进度会保存吗？
A：页面是免登录模式，勾选进度只存在当前浏览器页面里，刷新或关闭后会清空，
   不会上传或同步到任何系统，可以放心使用。需要清空点右上角"重置进度"。

Q："一站式平台"的账号密码在哪里？
A：在页面底部"② 帮助与支持"区域，第三个卡片"一站式平台"下方直接展示，
   账号 K1-visitor，密码 Tencent@K1visitor，点击即可复制。

Q：打开后是空白 / 没有样式？
A：多半是文件没放全，请按【三】的方式保证 4 个文件在同一目录下，
   或者直接用 standalone.html 这个单文件版。
